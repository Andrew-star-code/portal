# Инфопортал «Векта-Прибор»

PHP + SQLite, без фреймворков и сборки. Публичная часть сделана по макету, контент редактируется в админ-панели `/admin`.

## Что умеет

- **Главная**: 4 последние новости + слайдер продукции (слайды настраиваются в админке).
- **Разделы и страницы**: верхнее меню и подвал строятся из разделов и страниц в базе. Адреса вида `/buro/about`, `/products/avionics`.
- **Новости**: список с постраничной навигацией `/news`, отдельная страница `/news/<адрес>`, обложка, анонс.
- **Вкладки меню трёх типов** (задаётся в «Разделы меню»):
  - *выпадающий список страниц* — как «Бюро», «Продукция»;
  - *своя страница (каталог)* — вкладка сразу открывает страницу с плитками категорий. Категории вкладываются друг в друга на любую глубину, в любой категории — инструкции (PDF с просмотром в браузере, MP4/WebM со встроенным плеером, кнопка «Скачать»). Адреса вида `/cad/kompas/3d/sborka`. Управление — «Каталоги» в админке;
  - *ссылка* — ведёт на другую страницу сайта или внешний адрес.
  Если вкладки не помещаются в строку, меню само сворачивается в «бургер».
- **Админ-панель** `/admin`: новости, страницы, разделы меню, каталоги, слайды, настройки (логотип, адрес, телефон, e-mail), пользователи, смена пароля. Визуальный редактор текста с загрузкой картинок (кнопка или перетаскивание), таблицами и режимом HTML-кода.
- `sitemap.xml`, `robots.txt`, страница 404.
- **Работает без интернета** (например, в закрытой сети предприятия): внешних подключений нет, шрифт Roboto лежит локально в `public/assets/fonts/` (лицензия SIL OFL 1.1).

Безопасность: пароли хранятся в виде хеша (bcrypt), CSRF-токены на всех формах, защита от перебора пароля (5 попыток за 15 минут с одного IP), HTML из редактора чистится по белому списку тегов, в загрузки пропускаются только настоящие изображения, выполнение скриптов в `uploads/` запрещено, каталоги `app/` и `data/` закрыты.

## Требования

- Apache 2.4 с модулем `mod_rewrite` (желательно ещё `mod_headers`, `mod_expires`, `mod_deflate`).
- PHP 8.1 или новее с расширениями `pdo_sqlite`, `mbstring`, `fileinfo`, `dom` (в стандартных сборках обычно уже есть).

Проверить расширения: `php -m | grep -Ei "pdo_sqlite|mbstring|fileinfo|dom"`.

## Развёртывание

1. Скопируйте проект на сервер, например в `/var/www/portal`.
   Файлы `Dockerfile` и `docker-compose.yml` нужны только для локальной проверки, на сервер их можно не копировать.

2. Настройте виртуальный хост так, чтобы **DocumentRoot указывал на `public/`**:

   ```apache
   <VirtualHost *:80>
       ServerName portal.example.ru
       DocumentRoot /var/www/portal/public

       <Directory /var/www/portal/public>
           AllowOverride All
           Require all granted
       </Directory>

       ErrorLog ${APACHE_LOG_DIR}/portal-error.log
       CustomLog ${APACHE_LOG_DIR}/portal-access.log combined
   </VirtualHost>
   ```

   ```bash
   sudo a2enmod rewrite headers expires deflate
   sudo a2ensite portal && sudo systemctl reload apache2
   ```

   Если DocumentRoot поменять нельзя (виртуальный хостинг) и он указывает на корень проекта, сработает корневой `.htaccess`: он перенаправит запросы в `public/` и закроет служебные каталоги. Для этого нужен `AllowOverride All`.

3. Дайте веб-серверу права на запись в `data/` (там база) и `public/uploads/` (картинки):

   ```bash
   sudo chown -R www-data:www-data /var/www/portal/data /var/www/portal/public/uploads
   ```

4. При необходимости создайте `config.php` (скопируйте из `config.example.php`). Без него используются настройки по умолчанию из `app/config.default.php`.

5. Создайте администратора (база и начальный контент из макета создаются автоматически при первом обращении):

   ```bash
   cd /var/www/portal
   sudo -u www-data php bin/create-admin.php admin
   ```

   Скрипт спросит пароль (от 10 символов). Та же команда для существующего логина сбрасывает пароль.

   Нет доступа по SSH? Пропишите в `config.php` `'setup_key' => 'длинная-случайная-строка'`, откройте `/admin/setup`, создайте администратора и уберите ключ из конфига.

6. Откройте `https://ваш-домен/admin` и войдите.

7. Включите HTTPS (например, `sudo certbot --apache`). Cookie админки автоматически становятся `Secure` при работе по HTTPS.

### Установка в подкаталог

Если сайт открывается как `https://example.ru/portal/`, префикс определяется автоматически. Если автоопределение не сработало, укажите его в `config.php`: `'base_url' => '/portal'`.

## Загрузка больших файлов (видеоинструкции)

Приложение принимает инструкции до 600 МБ (`file_max_mb` в `config.php`). Лимиты PHP уже прописаны:

- `public/.user.ini` — для PHP-FPM / CGI (применяется в течение ~5 минут, `user_ini.cache_ttl`);
- `public/.htaccess` — для mod_php.

Проверить, что лимиты применились: откройте форму новой инструкции в админке — в подсказке под полем файла указан фактический лимит сервера. Если там меньше, чем нужно, хостинг игнорирует эти файлы — задайте в php.ini (или в панели хостинга):

```ini
upload_max_filesize = 600M
post_max_size = 610M
max_input_time = 900
max_execution_time = 900
```

Также убедитесь, что в Apache не задан меньший `LimitRequestBody` (по умолчанию в Apache 2.4.54+ — 1 ГБ, этого достаточно), а при работе за nginx-прокси — `client_max_body_size 610m;`.

Видео отдаёт сам Apache, поэтому перемотка работает без дополнительных настроек. Лучше загружать MP4 с кодеком H.264 — такое видео играет во всех браузерах.

## Резервное копирование

Весь контент — это файл `data/portal.sqlite` и каталог `public/uploads/` (картинки и файлы инструкций в `uploads/files/`). При обновлении кода база обновляется автоматически при первом обращении, данные сохраняются. Для консистентной копии базы на работающем сайте:

```bash
sqlite3 data/portal.sqlite ".backup data/backup-$(date +%F).sqlite"
```

## Локальная проверка (Docker)

```bash
docker compose up --build
```

Сайт откроется на http://localhost:8080. Администратора создайте так:

```bash
docker compose exec -u www-data web php bin/create-admin.php admin
```

Если база не создаётся из-за прав, выполните `docker compose exec web chown -R www-data data public/uploads`.

## Структура

```
app/            код (закрыт от веба)
  views/        шаблоны сайта и админки
  db.php        схема БД и начальное наполнение
  site.php      маршруты сайта
  admin.php     маршруты и обработчики админки
bin/            консольные скрипты
data/           база SQLite (создаётся автоматически, закрыт от веба)
public/         DocumentRoot: index.php, assets/, uploads/
```
